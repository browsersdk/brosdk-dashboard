# 产品定位

## 一句话定位

BroSDK Dashboard 是面向多账号运营者和自动化开发者的 Windows 多环境指纹浏览器控制中心，统一管理环境、代理、内核、关键指纹、运行状态和受控 AI 自动化。

## 目标用户

主要用户：

- 在一台 Windows 设备上管理多个店铺、账号或业务身份的运营人员。
- 需要稳定启停、定位、诊断和批量管理浏览器环境的团队管理员。

次要用户：

- 使用 BroSDK、MCP 或 AI Agent 构建浏览器自动化的开发者。
- 需要检查 DLL、运行时、环境和页面工具状态的支持与测试人员。

当前不面向：

- 需要云端多租户、团队权限和集中调度的企业控制台。
- 需要采购、财务、仓储、利润核算等完整能力的 ERP 用户。
- 没有对应平台动态库却要求完整功能的 macOS/Linux 用户。
- 试图绕过平台授权、风控或安全边界的自动化场景。

## 核心价值

1. 可靠：环境状态来自 DLL callback、浏览器运行信息和实时 MCP 对账，不把本地旧缓存当作运行事实。
2. 易懂：普通创建只选择代理和内核，复杂指纹策略由服务端默认值处理。
3. 可控：环境写操作、MCP mutation 和 AI Agent 都经过 Manager、operation、状态校验和审计。
4. 可恢复：Host 与桌面进程隔离，失败操作有明确状态，客户端重启后重新对账。
5. 可扩展：Dashboard 不直接依赖 DLL，未来平台实现通过 Host、IPC 和 platform adapter 接入。

## 核心工作流

### 首次启动

用户输入 API Key，客户端完成 getUserSig(role=user)、SDK 初始化、环境同步和本机安全存储。初始化失败时停留在可重试状态，不进入半初始化工作区。

### 多环境工作台

用户可以搜索环境、查看状态和关键配置，创建、启动、停止、批量操作、刷新详情、删除服务端环境或清理本地浏览数据。所有身份关联都使用 envId，名称允许重复。

### 资源管理

代理与内核是创建和运行环境的前置资源。代理凭据由系统安全存储保护；内核列表合并服务端 catalog、SDK 初始化信息和本地 cores，并按当前平台与架构过滤。

### 自动化

Chat 只执行受限读取；Agent 可以提出环境生命周期或页面操作。会话创建时固定为全局或单环境，单环境会话不能切换 envId。自动执行不应等于无限权限，高风险工具必须由风险策略单独约束。

### 诊断与恢复

操作中心、运行时对账、SDK 自检、代理诊断和脱敏日志用于解释失败原因。诊断能力是系统支持面，不应主导普通用户的日常导航。

## 数据所有权

| 数据 | 事实来源 | 本地职责 |
| --- | --- | --- |
| 环境配置、名称、指纹、服务端代理和内核 | SDK 服务端 | 脱敏、可删除缓存 |
| 环境运行状态 | 当前 DLL/runtime | operation、callback 和对账快照 |
| API Key、AI Key、代理密码 | 用户和对应服务 | 平台安全存储 |
| operation、设置、诊断摘要 | 本机 Manager | 本地事实 |
| AI 会话 | 当前为 WebView 本地数据 | 正式发布前迁入受保护存储或提供不持久化模式 |
| 分组、标签、收藏、备注 | 未来本地工作区 | 独立 overlay，不覆盖服务端环境字段 |

## 信息架构

当前界面已经按正式产品方向收敛为五个一级入口，页面深链继续使用稳定的 `page=` 参数，便于测试、文档截图和支持人员定位：

| 一级入口 | 包含内容 |
| --- | --- |
| 工作台 | 运行总览、最近环境、运行中环境、失败任务和快捷操作 |
| 环境 | 环境列表、详情、关键指纹、批量操作和未来本地组织 |
| 自动化 | AI 会话、任务计划和执行结果 |
| 资源 | 代理、内核、未来 Cookie/Storage 和扩展 |
| 系统 | 设置、操作记录、MCP 控制台、SDK 自检和诊断 |

桌面侧栏只展示五个任务入口；组内页面通过标题区二级标签切换。移动布局同样保留五个底部入口，避免把 MCP、操作和设置等高级项挤进普通用户的第一层导航。

## 非目标

- 不在普通创建表单暴露完整指纹 JSON、customerId 或任意服务端 DTO。
- 不把 SQLite 环境缓存升级为远端环境配置的主数据库。
- 不让 Dashboard 直接持有 userSig、调用 DLL、访问内部 SDK HTTP 或绕过 Manager 写操作。
- 不以固定 MCP 工具数量作为产品契约；工具以 DLL 当次 tools/list 为准。
- 1.0 前不建设完整跨境 ERP。

## 正式发布定义

正式发布不是“能够构建安装包”，而是同时满足：

- 可靠：核心生命周期、回调、重启恢复和失败收敛有自动化与真实环境验证。
- 易懂：首次启动和常用操作不需要理解 DLL、CDP、MCP 或 operation 内部概念。
- 安全：CSP、密钥、AI 历史、日志脱敏和高风险工具审批达到发布门槛。
- 可维护：版本、数据库迁移、DLL 兼容、升级和回滚有明确策略。
- 可交付：安装包签名，支持的 Windows 版本、许可、隐私和已知限制公开。
